# 🚀 Exercícios de Lógica de Programação em JavaScript

Repositório com exercícios de lógica de programação convertidos de Portuguol para **JavaScript**, cobrindo estruturas condicionais, laços de repetição (`while`, `do...while`, `for`) e operações matemáticas.

## 🛠️ Tecnologias

- **HTML5** & **CSS3**
- **JavaScript **

## 📚 Conteúdo

- **Faccat (`JSFaccat/`)**: Exercícios de lógica básica e estruturas de decisão.
- **Manzano (`JSManzano/`)**: Listas L01 a L05 focadas em condicionais e laços de repetição.
